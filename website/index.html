How It Works

별도 기기 없이,
어르신 기존 전화기로 바로 시작

보호자가 앱에서 설정하면, 나머지는 케어링이 알아서 합니다.

01

보호자 설정

통화 주기(매일 / 주 3회), 선호 시간대, 어르신의 관심사를 앱에서 설정합니다.

02

AI 발신 통화

설정된 시간에 AI가 어르신께 전화를 겁니다. 기존 휴대폰이나 유선전화로 자연스럽게 대화를 나눕니다.

03

음성 건강 분석

응답 속도, 발화 속도, 침묵 빈도, 감정 임베딩 벡터를 분석해 건강 트렌드를 추적합니다.

04

주간 리포트 발송

분석 결과를 AI가 자연어로 요약해 보호자에게 주간 리포트를 발송합니다.

Features

가족이 직접 설정하고,
가족이 직접 받아보는 리포트

공공 서비스와 달리, 케어링은 처음부터 가족을 위해 설계되었습니다.

📞

AI 자연어 통화

GPT-4o 기반 한국어 자유 대화. 어르신의 관심사(취미, 가족, 건강 이력)를 반영해 매 통화를 개인화합니다.

📊

음성 건강 지표 분석

단일 통화가 아닌 30/90일 트렌드 기반으로 응답 지연, 발화 속도, 감정 변화를 측정해 오탐률을 최소화합니다.

📋

주간·월간 보호자 리포트

비전문가도 이해할 수 있는 자연어 요약. 웰니스 지표 기반으로 표현하여 의료기기 규제를 회피합니다.

🚨

응급 키워드 즉시 알림

'넘어졌어', '아파' 등 응급 키워드 감지 시 보호자에게 즉시 푸시 알림을 발송합니다.

📱

어르신 발신 통화 (Premium)

어르신이 언제든 AI에게 먼저 전화할 수 있는 가상번호를 제공합니다. 외로움 해소와 응급 상황 보고가 모두 가능합니다.
